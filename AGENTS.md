# Little Mountain Metalworks

Read BUILD_STATUS.md before continuing the app. Update its milestone log with the completed behavior, verification results, and remaining work after every milestone.

The web application is in `apps/web`. Use the installed version in `apps/web/package.json` when checking Next.js conventions. The pinned Next.js 15 distribution uses the [versioned App Router documentation](https://nextjs.org/docs/15/app). Run the root workspace commands so SQLite, fixtures, and server settings resolve to the intended desk.

For geometry changes, run the Python CAD suite and validate the sketch release through the web flow. For pricing changes, check the dollar totals, batch versus per-piece behavior, approved version archive, and both staff and customer exports. Use isolated data directories for verification.
